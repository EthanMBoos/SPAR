# 09 — Build utility props

Build every `cable_spool`, `pipe_stack`, `bollard`, and `cone` anchor, and
nothing else.

Create one semantic root per anchor. Use simple recognizable local silhouettes:
two flanges and a hub for each spool; several parallel cylinders on supports
for each pipe stack; one post for each bollard; and a base plus tapered body for
each cone. Use real scale and restrained placeholder colors. No object may be
saturated red.

Finish in Solid Material Color mode and save
`<REPO>/artifacts/worldgen/<WORLD>/09_utility_props.blend`.
