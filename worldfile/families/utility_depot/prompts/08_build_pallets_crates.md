# 08 — Build pallets and crates

Build every `pallet` and `crate` anchor, and nothing else.

Create one semantic root per anchor. Build pallets from a few local deck slats
and blocks; build crates from a main box plus restrained frame pieces. Use
realistic dimensions from the anchors and muted wood placeholder materials.
Do not move existing assemblies or fill a planned aisle.

Finish in Solid Material Color mode and save
`<REPO>/artifacts/worldgen/<WORLD>/08_pallets_crates.blend`.
