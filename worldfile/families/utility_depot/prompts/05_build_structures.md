# 05 — Build structures and cabinets

Build only anchors whose `worldfile_plan_type` is `structure` or
`utility_cabinet`.

Create one semantic root at each matching anchor. Make the structure a simple,
recognizable covered work shed with local posts, roof, pad, and workbench while
keeping its open side usable. Make each cabinet a real-scale enclosure with a
body and shallow door. Use restrained placeholder colors and keep the result a
blockout rather than final detail.

Finish in Solid Material Color mode and save
`<REPO>/artifacts/worldgen/<WORLD>/05_structures.blend`.
