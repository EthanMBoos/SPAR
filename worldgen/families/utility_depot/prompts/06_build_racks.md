# 06 — Build storage racks

Build every anchor whose `spar_plan_type` is `rack`, and nothing else.

Create one semantic root per rack. At local coordinates, build an open steel
frame with four uprights, three shelf levels, horizontal beams, and a few
restrained loaded boxes or pipe bundles. Keep each planned aisle open and use
the anchor dimensions to size the rack. Use placeholder steel, wood, and muted
load colors.

Finish in Solid Material Color mode and save
`<REPO>/artifacts/worldgen/<WORLD>/06_racks.blend`.
